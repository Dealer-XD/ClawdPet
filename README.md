## Возможности

- Стоит на панели задач и на окнах, катается вместе с ними, падает/летает, отскакивает, повисает на верхнем краю, прячется, выглядывая из-за края экрана
- Реагирует на клики, поглаживание, перетаскивание и броски; танцует под музыку; комментирует открываемые программы
- Таскает иконки запущенных программ с панели задач и ест их (а иногда оставляет кучку, которую нужно убрать)
- По желанию — реплики от ИИ по API ключу и локальная память о вас
- 3 размера, 7 цветов, каждое поведение можно выключить, есть автозапуск с Windows

Меню и окно настроек оформлены как терминал Claude Code

## Управление

| Действие | Что происходит |
| --- | --- |
| Клик | Ткнуть. Много быстрых кликов подряд обижают Clawd |
| Двойной клик | Высокий прыжок с искрами |
| Зажать и водить мышью вправо-влево | Гладите Clawd и появляются сердечки и счастливое лицо |
| Перетащить | Перенести Clawd |
| Перетащить и резко отпустить | Бросок. Голова у Clawd может закружиться |
| Отпустить у верхнего края экрана | Повиснет на руках, потом упадёт |
| Клик по кучке | Убрать |
| Правый клик по Clawd | Открыть меню |
| Иконка в трее, левый клик | Позвать Clawd к курсору |
| Иконка в трее, правый клик | Открыть меню |

## Настройки

Открываются из меню «Настройки…». Изменения применяются сразу

| Вкладка | Что внутри |
| --- | --- |
| питомец  | Показ, размер, цвет; гравитация, катание на окнах, слёт при тряске окна, прогулки, реплики, кража иконок, время до сна, танцы, комментарии к программам, кучки, прятаться на весь экран, автозапуск |
| ии  | Провайдер (список пресетов), API-ключ, модель, адрес API, как часто болтает, эмоции и движение от ИИ, заголовки окон, обычные фразы как запасной вариант, характер, запасной провайдер, проверка связи |
| мозг  | Включить память, ваше имя, «о себе», запоминание фактов, передача памяти ИИ, показать память, перенос из плагина, папка с данными, «забыть всё» |
| о программе | Краткая справка |

## Реплики от ИИ (по желанию, по умолчанию выключено)

1. Откройте «Настройки» → «ии» и включите ИИ.
2. Выберите провайдера в списке: Google Gemini, OpenAI, OpenRouter, Groq, DeepSeek, Mistral, Together AI, LM Studio, Ollama или «Свой» (любой сервер с `/chat/completions`). Адрес API и модель подставятся сами, при желании их можно изменить.
3. Вставьте API-ключ. Его создают в личном кабинете выбранного провайдера (для Gemini — на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)). LM Studio и Ollama работают локально и ключа не требуют.
4. Нажмите «Проверить ИИ».

Что важно знать:

- Если поле «Модель» пустое, используется модель по умолчанию (задана в `Constants.cs`). Для некоторых провайдеров её нужно указать самому, а свою модель можно ввести всегда.
- Модель должна отвечать небольшим JSON-объектом: `say` (реплика), `mood` (одна из 13 анимаций), `action` (одно из 12 движений) и необязательное `remember` (новый факт о вас). Если ИИ недоступен, Clawd переключается на встроенные фразы (это можно отключить).
- Запросы ограничены по частоте (раз в несколько секунд). При ошибке 429 или проблемах с авторизацией провайдер ненадолго отключается.
- **Запасной провайдер** выбирается так же, как основной, и используется, если основной не ответил.
- «Как часто болтает сам» управляет репликами без повода: часто, нормально, редко, никогда.
- Поле «Характер» дописывается к системному промпту, так что личность Clawd можно менять.

## Память («мозг»)

Clawd записывает, что происходит (поглаживания, броски, съеденные иконки, открытые программы, треки, как часто вы заходите), в файл `clawd_brain.json`:

- **Привязанность** от 0 до 100, пять уровней: знакомый, приятель, друг, близкий друг, лучший друг. Растёт, когда вы добры к нему, и немного падает, если сильно бросать его, трясти окно или не появляться несколько дней.
- **Факты**, которые ИИ решил запомнить о вас (до 40, похожие склеиваются, ссылки, длинные числа и всё похожее на пароли или инъекции промпта отбрасывается).
- **Привычки**, выведенные из статистики: когда вы обычно заходите, что слушаете.
- **Недавние события** как контекст для реплик.

Формат файла совместим с `clawd_brain.json` из исходного плагина для exteraGram, поэтому уже накопленную память можно перенести («Настройки» → «мозг» → перенос из плагина).

## Приватность и данные

- Всё хранится локально в `%APPDATA%\ClawdPet\`: `config.json` (настройки), `clawd_brain.json` (память), `clawd.log` (ошибки, обрезается примерно на 512 КБ).
- **API-ключи лежат в `config.json` открытым текстом.** В окне настроек они скрыты, а в файле нет. Не делитесь этой папкой.
- Единственный сетевой трафик идёт к настроенному вами ИИ-провайдеру. При выключенном ИИ ClawdPet **не делает сетевых запросов**.
- При включённом ИИ запрос может содержать: описание ситуации, местное время, название программы на переднем плане, сколько раз вы её открывали, текущий трек (исполнитель и название), положение Clawd на экране и его последние реплики.
  - Заголовки окон отправляются **только** если включено «Передавать ИИ заголовки окон».
  - Блок памяти (ваше имя, «о себе», факты, привычки, недавние события) отправляется **только** при включённом «Делиться памятью с ИИ».
  - Пока вы не задали имя сами, Clawd использует имя пользователя Windows (если оно не вроде `user` или `admin`).
- Чтобы видеть рабочий стол, ClawdPet перечисляет окна и их положение, определяет активную программу, имена процессов и их иконки, время бездействия и текущую медиасессию. Он не снимает экран, не записывает нажатия клавиш и не читает буфер обмена.

## Требования

- Windows 10 версии 1809 (сборка 17763) или новее
- Для сборки: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (проект использует WPF и Windows Forms, поэтому собирается под Windows)
- Для запуска зависимой от фреймворка сборки: .NET 8 Desktop Runtime

## Известные ограничения

- Только Windows.
- Интерфейс, встроенные фразы и ответы ИИ только на русском, слоя локализации пока нет.
- Автоматических тестов нет.

## О проекте

ClawdPet — порт плагина ClawdPetPlugin для exteraGram на Windows (оригинал — @itskotovski, форк — @Skorvash).

Это неофициальный фанатский проект. Он не связан с Anthropic, не одобрен и не спонсируется ею. «Claude» — товарный знак Anthropic.
