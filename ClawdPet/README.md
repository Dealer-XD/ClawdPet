# Clawd для Windows

Порт плагина `clawd_pet.plugin` для exteraGram на C# / WPF (.NET 8).
Пиксельный питомец Claude живёт поверх всех окон, гуляет по панели задач и по верхним краям окон.

## Запуск

* **Готовый exe** — `ClawdPet.exe` (самодостаточный, .NET ставить не нужно). Windows 10 1809+ / Windows 11, x64.
* После запуска Clawd появится над панелью задач, а в трее — его иконка.
  * ЛКМ по иконке в трее — позвать к курсору. ПКМ — меню.
  * ПКМ по самому Clawd — то же меню.

## Сборка из исходников

```
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true
```
Нужен .NET 8 SDK. Можно открыть `ClawdPet.csproj` в Visual Studio 2022 / Rider.

## Управление

| Действие | Что делает |
|---|---|
| Клик | ткнуть (6 кликов подряд — обидится) |
| Двойной клик | прыжок |
| Зажать на 0,4 с и водить туда-сюда | погладить (сердечки) |
| Перетащить | перенести |
| Резко бросить | полёт с отскоками; подброшенный к верху экрана — повиснет на руках |
| Меню → «Покормить» | кладёт печеньку, Clawd к ней подойдёт и съест |
| Клик по кучке | убрать |

## Что перенесено и что изменилось

| В плагине (Android/Telegram) | В Windows-версии |
|---|---|
| Спрайт 18×13, 6 палитр, 3 размера, все эмоции и анимации | 1:1 |
| Физика: ходьба, прыжки, бросок, отскоки, головокружение | 1:1 |
| Сон, подглядывание из-за края экрана, висение у статус-бара | 1:1 (висит у верхнего края экрана) |
| Стоит на пузырях сообщений и поле ввода | стоит на **верхних краях окон** и на панели задач; если окно двигать — катается на нём |
| Тряска телефона | **тряска окна**, на котором он стоит, — слетает кувырком |
| Наклон телефона (скольжение) | убрано (нет акселерометра) |
| Танцует под музыку в Telegram | танцует под **любой плеер Windows** (Spotify, браузер, Яндекс Музыка…) — через системные медиаконтролы, знает название трека |
| Комментирует открытые чаты | комментирует **открытые программы** (новая / снова та же), считает визиты |
| Реакции на входящие/исходящие сообщения | убрано (нет доступа к Telegram) |
| Ест кнопки интерфейса, выплёвывает | **ест печеньки** из меню; переевший оставляет кучку |
| «Ты вернулся» после паузы приложения | после 10+ минут без мыши и клавиатуры |
| ИИ: Gemini + OpenAI-совместимый, запасной провайдер, эмоции и движения от ИИ | 1:1, тот же формат JSON-ответа |
| «Мозг»: факты, привычки, привязанность, эпизоды | 1:1; **формат файла совместим** — `clawd_brain.json` с телефона можно импортировать (Настройки → Мозг) |
| Вибрация | убрано |
| — | Прячется, когда игра или видео на весь экран; автозапуск с Windows |

Данные лежат в `%APPDATA%\ClawdPet\` (`config.json`, `clawd_brain.json`, `clawd.log`).
API-ключ хранится там же открытым текстом, как и в плагине.

## Структура

```
src/Program.cs        точка входа, трей и меню
src/Pet.cs            состояния, физика, отрисовка (порт _step/_compose/_render)
src/PetActions.cs     мышь, музыка, программы, печеньки, кучки, частицы, пузырь
src/PetMind.cs        реплики, ИИ, память
src/Brain.cs          ClawdBrain (тот же JSON-формат)
src/Ai.cs             запросы к Gemini / OpenAI-совместимым API
src/Sprites.cs        пиксельный рендер спрайта и частиц
src/Windows.cs        прозрачные окна поверх всех (питомец, печенька, кучка)
src/Desktop.cs        поиск окон-платформ, активная программа, полноэкранный режим
src/Media.cs          системный медиаплеер Windows
src/SettingsWindow.cs окно настроек
src/Constants.cs      фразы, ситуации для ИИ, палитры, узоры
```
